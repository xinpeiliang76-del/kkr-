2026-10-22技术备忘

这篇既是备忘，也是写新文章时可以照着抄的模板。直接复制这个文件、改个名字就能开始写。

标题

用 # 开头，# 越多层级越低。正文里一般用 ##，因为 # 留给文章标题。

强调

两个星号是加粗，一个星号是斜体，反引号是行内代码。

列表

无序列表：

  • 第一项
  • 第二项
  • 第三项

有序列表：

  1. 第一步
  2. 第二步
  3. 第三步

引用

引用一段别人的话，或者给自己留个批注。第二行会接在同一个引用块里。

代码

行内代码长这样：npm run build。

代码块用三个反引号包起来：

function hello(name) {
  console.log(`你好，${name}`);
}

链接和图片

链接：GitHub Pages 文档

图片：![图片说明](图片地址)，图片文件放在 assets/ 目录里，路径写成 ../assets/xxx.png（文章在 posts/ 子目录下，所以要先退一级）。

分隔线

三个减号就是一条分隔线。

文件命名规则

posts/ 里的文件名决定网址：

2026-10-22-markdown-cheatsheet.md

开头的日期会被识别成发布日期，后面的部分变成网址 docs/posts/markdown-cheatsheet.html。所以改了文件名，旧链接就失效了，发布之后别再改名。

日期也可以写在文件头里：

---
title: 文章标题
date: 2026-10-22
tags: 技术, 备忘
---

title 是文章标题，tags 用逗号分隔。
