这个站

一个人的政治哲学笔记。

主站文章是《冲突、纠错与解放——一种以劳动者主体性、制度自我纠错与有限抵抗权为核心的社会主义政治哲学》的纲要与导读；另有一份左翼思想谱系，用来说明这套框架在思想史里的位置——以及它和哪些传统有分歧。

没有评论区，没有推荐算法，没有后台。所有文章是纯文本的 Markdown 文件，放在 GitHub 上。

关心的问题

社会如何在不靠消灭冲突的前提下保持稳定；劳动者的判断能力如何成为制度的一部分；国家怎样做到"强到能治理，弱到不能吞并社会"；以及一个制度如何为自己保留被纠正的可能。

这些问题没有终解。这里记录的只是某个阶段的答案。

写作原则

  • 先区分概念，再谈立场；
  • 论证要能被反驳，否则不算论证；
  • 问题解决了，讨论就应当停止；
  • 不因为观点不同就把人归入敌我。
